# Local measurements

Default outputs are grouped here: `mem_log/`, `faiss/`, `energy_raw/`,
`energy_profiles/` and `similarity_*` experiment directories. `ANN_RESULTS_DIR`
selects another root. Explicit output arguments still select their exact paths.

`legacy/` and `profiles/` hold older root CSV/log/plot files and Tracy
captures. Historical reports may still contain their original absolute paths.

Raw measurements are ignored by Git. Document selected, attributed results in
`docs/RESULTS.md`; distribute the raw files separately.
